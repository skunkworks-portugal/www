# Skunkworks Portugal

Public website for Skunkworks Portugal, built from the shared [Skunkworks web design system](https://github.com/skunkworks-africa/theme).

## Local preview

The site has no build step. Serve the repository root with any static HTTP server, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

GitHub Pages deploys the `main` branch automatically through `.github/workflows/pages.yml`.

## Brand provenance

- Design tokens and country-site standards: `skunkworks-africa/theme`
- Approved black and white marks: Skunkworks brand kit, preserved without recolouring or distortion
- Country designation remains separate text, following the shared brand standard
